# POOM

소중한 메시지와 마음을 보관하는 개인용 아카이브 서비스.  
채팅 스크린샷을 업로드하면 OCR로 보낸 사람을 자동 인식하고, 날짜·폴더별로 정리해 언제든 다시 꺼내볼 수 있습니다.

**→ [poom.app 바로가기](https://kmyumn.github.io/2026-Vibe-Coding-Seminar/)**

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 마음 보관 | 채팅 스크린샷 업로드 → OCR 자동 인식 → 보낸 사람·날짜·폴더 지정 후 저장 |
| 홈 | 최근 받은 마음 / 최근 다시 읽은 마음 카드 피드 |
| 품(폴더) | 폴더별 마음 목록 · 월별 그룹 · 검색 · 기본 폴더 고정 |
| 찾기 | 내용·보낸 사람 전문 검색, AI 표현 감지 배지 |
| 받은 마음 상세 | 메시지 카드 + 표현 태그 분석 + 같은 사람 마음 목록 + 엽서 CTA |
| 삭제 | 카드 꾹 누르기(600ms) → 지우기 버튼 |

---

## 기술 스택

- **순수 HTML / CSS / JS** — 빌드 도구 없음, 파일 1개로 완결
- **IndexedDB** — 이미지·메타데이터 로컬 영구 저장
- **Tesseract.js (CDN)** — 클라이언트 사이드 OCR (한국어)
- **Canvas 압축** — 업로드 이미지를 최대 1080px / JPEG 0.82로 리사이즈 후 저장
- **GitHub Pages** — 별도 서버 없이 정적 배포

## 디자인 원칙

- 배경색 `#F7F0EB`, 포인트 `#FFB6A4`
- 폰트: **아리따돋움** T · M · SB (base64 임베드, 오프라인 지원)
- 컨테이너: **좌하단만 라운딩 없는** 형태 (`border-radius: R R R 0`)
- 그라디언트·이모지 없음, 미니멀 단색 UI

## 화면 구성

```
홈 (Home)
├── 히어로 카드 — "간직하고 싶은 메시지가 있나요?"
├── 최근 받은 마음 (카드 피드)
└── 최근 다시 읽은 마음 (카드 피드)

품 (Library)
├── 보관된 마음 수 요약
├── 폴더 카드 목록 (기본 폴더 항상 고정 · 삭제 불가)
└── 폴더 상세 → 월별 메시지 + 검색바

찾기 (Search)
├── 검색 인풋
└── 검색 결과 카드 (이미지 오버레이 + AI 표현 감지 배지)

받은 마음 상세 (Detail)
├── 메시지 카드 (이미지 + 보낸사람 chip + 날짜 chip)
├── 표현 태그 분석 (OCR 기반 빈도 추출)
├── 통계 — "마음마다 N번씩 다시 읽었어요"
├── 자주 다시 읽은 마음 (가로 스크롤)
├── 같은 사람에게 받은 마음 전체 목록
└── 하단 CTA — "X님에게 보낼 엽서 만들기"

업로드 플로우 (3-step)
├── Step 1: 인식 중 (Tesseract OCR · 캐러셀)
├── Step 2: 정보 확인 (날짜·폴더·보낸 사람 수정)
└── Step 3: 보낸 사람 검색·선택 (다중 선택)
```

## 로컬 실행

```bash
node server.js
# http://localhost:3000 에서 확인
```

또는 서버 없이 바로 열기:

```bash
open index.html
```

> IndexedDB는 `file://` 프로토콜에서 일부 브라우저(Safari 등)가 제한할 수 있습니다.  
> 제한 환경에서는 자동으로 메모리 모드로 동작합니다 (새로고침 시 데이터 초기화).
